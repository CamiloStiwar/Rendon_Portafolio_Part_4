Team project · Website

Futbol Penalty Kick Tracker

Java · OOP · File I/O

A Java console program that simulates a soccer penalty shootout. Users create an account and log in (saved to a text file), enter two teams and their kickers, and play 5 rounds plus sudden death if needed.

What I learned

Using classes and objects, and reading and writing data to files so it is saved between runs.

Lost in the Everglades

C++ · 2D Arrays · Random Numbers

A C++ text RPG where a Ranger crosses a 5x5 map to rescue tourists before 12 gongs run out. Hidden dangers like alligators and pythons appear at random, and the player chooses to wait or fight.

What I learned

Working with 2D arrays for the map and using random numbers to make every game different.
